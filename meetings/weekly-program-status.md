# Weekly Program Status — Agenda

> Fictional / illustrative template.

**When:** Thu 18:00 PT / Fri 10:00 Taipei / Fri 07:30 IST (60 min)
**Owner:** Program TPM · **Pre-read:** this week's status report (`artifacts/status-report.md`), updated risk register

## Agenda

| Time | Item |
|---|---|
| 0:00–0:05 | Schedule snapshot: milestones due in the next 2 weeks, any slip |
| 0:05–0:20 | Red / yellow items only — owner, impact, mitigation, help needed |
| 0:20–0:35 | Gate readiness (if a gate is within 3 weeks): entry criteria checklist |
| 0:35–0:50 | Top risks: trigger watch — is any trigger close to firing? |
| 0:50–0:60 | Decisions needed this week (log them against the RACI) |

## Ground rules

- Green items get one line. The meeting is for risks and decisions.
- Every discussion ends with an **owner + due date**, captured in the notes.
- Notes published within 24h; open items roll to next week explicitly (no silent drops).

## Outputs

- Updated status report, updated risk register, decision log entries.
